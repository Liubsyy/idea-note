## 房贷计算器


```input {id=loan}
principal: number = 500000 {slider: 100000..3000000, step: 50000, label: 贷款总额, unit: 元}
rate:      number = 3.85   {slider: 1..8, step: 0.05, label: 年利率, unit: %}
years:     select = [10, 20, 25, 30] {default: 30, label: 贷款年限, unit: 年}
equal:     bool   = true   {label: 等额本息}
```

```python {in=loan, out=markdown, run=open,run=watch}
import json, os

principal = float(os.environ["principal"])
monthly_rate = float(os.environ["rate"]) / 100 / 12
months = int(os.environ["years"]) * 12

if os.environ["equal"] == "true":  # 等额本息
    growth = (1 + monthly_rate) ** months
    monthly = principal * monthly_rate * growth / (growth - 1)
    total = monthly * months
    headline = f"**月供 {monthly:,.2f} 元**（每月固定）"
else:  # 等额本金
    first = principal / months + principal * monthly_rate
    last = principal / months * (1 + monthly_rate)
    total = (first + last) * months / 2
    headline = f"**首月 {first:,.2f} 元，末月 {last:,.2f} 元**（逐月递减）"

result = (
    f"{headline}\n\n"
    f"- 利息合计：{total - principal:,.2f} 元\n"
    f"- 本息合计：{total:,.2f} 元"
)
print(json.dumps(result, ensure_ascii=False))
```

## 函数绘图仪（`out=image`）

预期结果：拖动振幅、频率、相位滑块，上方的曲线立刻重画。脚本只用标准库手写 SVG，再编码成 `data:` 地址交给 `out=image`——**不落盘**，所以拖滑块不会在 `assets/` 里堆一地临时图片，也不会遇到「文件覆盖了但图还是旧的」的缓存问题。

```input {id=wave}
kind:      select = [sin, cos, 衰减正弦, 方波] {label: 函数}
amplitude: number = 1.5 {slider: 0.1..2, step: 0.1, label: 振幅}
frequency: number = 3   {slider: 0.5..6, step: 0.5, label: 频率}
phase:     number = 45  {slider: 0..360, step: 15, label: 相位, unit: °}
grid:      bool   = true {label: 显示网格}
```

```python {in=wave, out=image, run=watch}
import base64, json, math, os

kind = os.environ["kind"]
amp = float(os.environ["amplitude"])
freq = float(os.environ["frequency"])
phase = math.radians(float(os.environ["phase"]))

W, H, PAD = 640, 260, 24
X_MAX, Y_MAX = 2 * math.pi, 2.2  # y 轴范围固定，振幅的变化才看得出来


def value(x):
    angle = freq * x + phase
    if kind == "cos":
        return amp * math.cos(angle)
    if kind == "衰减正弦":
        return amp * math.exp(-x / 3) * math.sin(angle)
    if kind == "方波":
        return amp * (1 if math.sin(angle) >= 0 else -1)
    return amp * math.sin(angle)


sx = lambda x: PAD + x / X_MAX * (W - 2 * PAD)
sy = lambda y: H / 2 - y / Y_MAX * (H / 2 - PAD)

parts = [
    f'<svg xmlns="http://www.w3.org/2000/svg" width="{W}" height="{H}" viewBox="0 0 {W} {H}">',
    f'<rect width="{W}" height="{H}" rx="8" fill="#f8fafc"/>',
]

if os.environ["grid"] == "true":
    for i in range(1, 8):
        x = PAD + i / 8 * (W - 2 * PAD)
        parts.append(f'<line x1="{x:.1f}" y1="{PAD}" x2="{x:.1f}" y2="{H - PAD}" stroke="#e2e8f0"/>')
    for level in (-2, -1, 1, 2):
        parts.append(f'<line x1="{PAD}" y1="{sy(level):.1f}" x2="{W - PAD}" y2="{sy(level):.1f}" stroke="#e2e8f0"/>')

parts.append(f'<line x1="{PAD}" y1="{sy(0):.1f}" x2="{W - PAD}" y2="{sy(0):.1f}" stroke="#94a3b8"/>')

points = " ".join(
    f"{sx(i / 240 * X_MAX):.1f},{sy(value(i / 240 * X_MAX)):.1f}" for i in range(241)
)
parts.append(f'<polyline points="{points}" fill="none" stroke="#2563eb" stroke-width="2"/>')
parts.append(
    f'<text x="{PAD}" y="{H - 6}" font-family="monospace" font-size="12" fill="#475569">'
    f"{kind}  A={amp:g}  f={freq:g}  φ={os.environ['phase']}°</text>"
)
parts.append("</svg>")

encoded = base64.b64encode("".join(parts).encode("utf-8")).decode("ascii")
print(json.dumps(f"data:image/svg+xml;base64,{encoded}"))
```

> `out=image` 的 `data` 也可以是磁盘路径（相对本笔记或绝对路径）或路径数组，适合脚本本来就会生成图片文件的场景；上面这种 `data:` 写法则适合「图随参数不停重画」的即时预览。




## 排期表变甘特图（`in=table:`）

预期结果：下面这张排期表被当成数据读进脚本，直接画成甘特图。人看表格、脚本读表格，**同一份数据不用维护两遍**——改完某一行的工期或状态，点一下运行，图就跟着变。

| 发布 | 灰度发布 | 小艾 | 2026-09-29 | 2 | 未开始 |

```python {in=table:项目排期, out=mermaid}
import datetime, json, os

rows = json.loads(os.environ["IDEA_NOTE_INPUT"])["rows"]
TAGS = {"已完成": "done", "进行中": "active"}

lines = ["gantt", "  dateFormat YYYY-MM-DD", "  axisFormat %m/%d"]
section = None
begin = end = None

for i, row in enumerate(rows, 1):
    start = datetime.date.fromisoformat(row["开始"])
    days = int(row["工期"])  # 表格单元格全是字符串，要算数就自己转
    stop = start + datetime.timedelta(days=days)
    begin = start if begin is None or start < begin else begin
    end = stop if end is None or stop > end else end

    if row["阶段"] != section:
        section = row["阶段"]
        lines.append(f"  section {section}")

    tag = f"{TAGS[row['状态']]}, " if row["状态"] in TAGS else ""
    lines.append(f"  {row['任务']}（{row['负责人']}） :{tag}t{i}, {start}, {days}d")

lines.insert(1, f"  title 项目排期 {begin:%m/%d} – {end:%m/%d}（共 {(end - begin).days} 天）")
print(json.dumps("\n".join(lines), ensure_ascii=False))
```

## 正则试验台（`text` 字段）

预期结果：改正则或改测试文本，下方立刻列出所有匹配、位置和捕获分组。正则写错了也不会红一片——脚本自己接住 `re.error`，把报错渲染成一张表。

> ⚠️ 参数块的一行里，**第一个 `{` 就被当成字段选项的开头**，所以正则默认值里不能出现 `{}`：要写 `\d\d\d\d` 而不是 `\d{4}`。带 `{n,m}` 的正则可以在控件里手输，只是没法当默认值写进笔记。

```input {id=regex}
pattern:    text = "([A-Za-z0-9._%+-]+)@([A-Za-z0-9.-]+\.[A-Za-z]+)" {label: 正则}
sample:     text = "联系 alice@example.com 或 Bob@Idea-Note.dev，抄送 team@corp.cn" {label: 测试文本}
ignorecase: bool = false {label: 忽略大小写}
```

```python {in=regex, out=table, run=watch}
import json, os, re

flags = re.IGNORECASE if os.environ["ignorecase"] == "true" else 0

try:
    matcher = re.compile(os.environ["pattern"], flags)
except re.error as exc:
    print(json.dumps({"columns": ["正则错误"], "rows": [[str(exc)]]}, ensure_ascii=False))
    raise SystemExit(0)

result = {"columns": ["#", "匹配", "位置", "分组"], "rows": []}
for i, m in enumerate(matcher.finditer(os.environ["sample"]), 1):
    groups = " | ".join(g if g is not None else "—" for g in m.groups())
    result["rows"].append([i, m.group(0), f"{m.start()}–{m.end()}", groups or "—"])

print(json.dumps(result, ensure_ascii=False))
```





## Git 提交统计（`bash` 运行器 + `run=open+watch`）

预期结果：打开笔记就自动跑一次，出一张按提交数排序的作者榜；拖动天数、填个作者名字，立刻重算。脚本在**笔记所在目录**执行，所以统计的就是这篇笔记所属的仓库。

> 作者留空时 `--author=""` 是一个空正则，匹配所有人，不用为「过滤/不过滤」写两条分支。

```input {id=gitlog}
days:   number = 30 {slider: 1..365, step: 1, label: 统计天数, unit: 天}
author: text   = "" {label: 作者过滤（留空=全部）}
```

```bash {in=gitlog, out=table, run=open+watch}
set -euo pipefail

if ! git rev-parse --is-inside-work-tree >/dev/null 2>&1; then
  echo "当前笔记不在 Git 仓库里" >&2
  exit 1
fi

git log --since="${days} days ago" --author="${author}" --pretty=format:'%an' \
  | sort | uniq -c | sort -rn \
  | awk '
      {
        n++; cnt[n] = $1
        $1 = ""; sub(/^[ \t]+/, "")
        gsub(/\\/, "\\\\"); gsub(/"/, "\\\"")   # 作者名里的引号要转义，否则 JSON 崩
        who[n] = $0; total += cnt[n]
      }
      END {
        printf "{\"columns\":[\"作者\",\"提交数\",\"占比\"],\"rows\":["
        for (i = 1; i <= n; i++)
          printf "%s[\"%s\",%d,\"%.1f%%\"]", (i > 1 ? "," : ""), who[i], cnt[i], cnt[i] * 100 / total
        printf "]}\n"
      }'
```





## 提交热力图（`out=html` 画图）

预期结果：一张 GitHub 风格的提交方格图，鼠标悬停能看到某一天的日期和提交数。`out=html` 只能出静态内容，但「静态」不等于「简陋」——图形本身由脚本每次重新生成，交互交给上面的滑块。

```input {id=heat}
weeks: number = 26 {slider: 4..52, step: 1, label: 回溯周数, unit: 周}
```

```python {in=heat, out=html, run=watch}
import datetime, json, os, subprocess

weeks = int(os.environ["weeks"])
start = datetime.date.today() - datetime.timedelta(days=weeks * 7 - 1)
start -= datetime.timedelta(days=(start.weekday() + 1) % 7)  # 回退到周日，方格才对得齐

log = subprocess.run(
    ["git", "log", f"--since={start}", "--pretty=format:%ad", "--date=short"],
    capture_output=True, text=True, check=True,
).stdout

counts = {}
for line in log.splitlines():
    counts[line] = counts.get(line, 0) + 1

LEVELS = ["#ebedf0", "#9be9a8", "#40c463", "#30a14e", "#216e39"]
peak = max(counts.values(), default=0)


def color(n):
    if n == 0 or peak == 0:
        return LEVELS[0]
    return LEVELS[min(4, 1 + (n - 1) * 4 // peak)]


cells = []
day, today = start, datetime.date.today()
while day <= today:
    n = counts.get(day.isoformat(), 0)
    cells.append(
        f'<span title="{day} · {n} 次提交" style="width:11px;height:11px;'
        f'border-radius:2px;background:{color(n)}"></span>'
    )
    day += datetime.timedelta(days=1)

legend = "".join(
    f'<span style="width:11px;height:11px;border-radius:2px;background:{c}"></span>'
    for c in LEVELS
)

html = (
    '<div style="padding:12px;border-radius:8px;background:#f8fafc;color:#475569;font-size:12px">'
    f'<div style="margin-bottom:8px">最近 {weeks} 周共 {sum(counts.values())} 次提交，'
    f"最忙的一天 {peak} 次</div>"
    '<div style="display:grid;grid-auto-flow:column;grid-template-rows:repeat(7,11px);'
    f'gap:3px;overflow-x:auto">{"".join(cells)}</div>'
    '<div style="display:flex;align-items:center;gap:3px;margin-top:8px">'
    f'<span style="margin-right:4px">少</span>{legend}'
    '<span style="margin-left:4px">多</span></div>'
    "</div>"
)
print(json.dumps(html, ensure_ascii=False))
```



## AI笔记助手生成的例子

### 1. 密码生成器

预期结果：调长度、勾字符类型，立刻生成一批高强度随机密码。用的是 `secrets`（加密安全随机数），可以当真实密码用。

```input {id=passgen}
length:  number = 16 {slider: 8..64, step: 1, label: 密码长度}
count:   number = 5  {slider: 1..20, step: 1, label: 生成数量}
lower:   bool   = true {label: 小写字母 a-z}
upper:   bool   = true {label: 大写字母 A-Z}
digits:  bool   = true {label: 数字 0-9}
symbols: bool   = true {label: 符号 !@#$...}
```

```python {in=passgen, out=markdown, run=watch}
import json, os, secrets, string

length = int(os.environ["length"])
count = int(os.environ["count"])

charset = ""
if os.environ["lower"] == "true":
    charset += string.ascii_lowercase
if os.environ["upper"] == "true":
    charset += string.ascii_uppercase
if os.environ["digits"] == "true":
    charset += string.digits
if os.environ["symbols"] == "true":
    charset += "!@#$%^&*()-_=+[]{};:,.?"

if not charset:
    print(json.dumps("**请至少勾选一种字符类型**", ensure_ascii=False))
    raise SystemExit(0)

lines = [f"**已生成 {count} 个 {length} 位密码**", ""]
for i in range(count):
    pw = "".join(secrets.choice(charset) for _ in range(length))
    lines.append(f"{i + 1}. `{pw}`")

print(json.dumps("\n".join(lines), ensure_ascii=False))
```

### 2. 单位换算器

预期结果：选类别、填数值和单位符号，立刻得到换算结果。支持长度、重量、数据（二进制）的系数换算，温度用公式换算。

```input {id=unit}
category:  select = [长度, 温度, 重量, 数据] {default: 长度, label: 类别}
value:     number = 1 {step: 0.01, label: 数值}
unit_from: text   = "km" {label: 从单位}
unit_to:   text   = "m" {label: 到单位}
```

```python {in=unit, out=table, run=watch}
import json, os

value = float(os.environ["value"])
category = os.environ["category"]
src = os.environ["unit_from"].strip().lower()
dst = os.environ["unit_to"].strip().lower()

BASE = {
    "长度": {"mm": 0.001, "cm": 0.01, "m": 1, "km": 1000,
             "in": 0.0254, "ft": 0.3048, "mi": 1609.344},
    "重量": {"mg": 1e-6, "g": 0.001, "kg": 1, "t": 1000,
             "lb": 0.45359237, "oz": 0.028349523125},
    "数据": {"B": 1, "KB": 1024, "MB": 1024 ** 2,
             "GB": 1024 ** 3, "TB": 1024 ** 4},
}

if category in BASE and src in BASE[category] and dst in BASE[category]:
    out = value * BASE[category][src] / BASE[category][dst]
    rows = [[f"{src} → {dst}", f"{value:g} {src}", f"{out:g} {dst}"]]
elif category == "温度":
    src0, dst0 = src.upper(), dst.upper()
    if src0 in "CFK" and dst0 in "CFK":
        c = {"C": value, "F": (value - 32) * 5 / 9, "K": value - 273.15}[src0]
        out = {"C": c, "F": c * 9 / 5 + 32, "K": c + 273.15}[dst0]
        rows = [[f"{src0}° → {dst0}°", f"{value:g} °{src0}", f"{out:.2f} °{dst0}"]]
    else:
        rows = [[f"温度单位只支持 C / F / K，收到 {src!r} / {dst!r}"]]
else:
    rows = [[f"类别「{category}」里找不到单位 {src!r} 或 {dst!r}"]]

print(json.dumps({"columns": ["换算", "原值", "结果"], "rows": rows}, ensure_ascii=False))
```

```python {in=color, out=html, run=watch}

raw = os.environ["hex"].strip().lstrip("#")
if len(raw) == 3:
    raw = "".join(c * 2 for c in raw)
if len(raw) != 6:
    print(json.dumps(
        "<p style='color:#dc2626;font:14px sans-serif'>颜色格式应为 #rrggbb 或 #rgb</p>",
        ensure_ascii=False))

mx, mn = max(r_, g_, b_), min(r_, g_, b_)
l = (mx + mn) / 2
if mx == mn:
    h, s = 0.0, 0.0
else:
    d = mx - mn

        h = (g_ - b_) / d + (6 if g_ < b_ else 0)
    elif mx == g_:
        h = (b_ - r_) / d + 2

        h = (r_ - g_) / d + 4

text_color = "#ffffff" if l < 0.5 else "#1e293b"

    f'<div style="display:flex;gap:14px;align-items:center;padding:12px;'
    f'border-radius:8px;background:#f8fafc">'
    f'<div style="width:76px;height:76px;border-radius:8px;background:#{raw};'
    f'border:1px solid #e2e8f0;display:flex;align-items:center;justify-content:center;'
    f'font:600 11px monospace;color:{text_color}">#{raw}</div>'
    f'<table style="font:13px monospace;border-collapse:collapse">'
    f'<tr><td style="padding:2px 10px;color:#64748b">HEX</td><td>#{raw}</td></tr>'
    f'<tr><td style="padding:2px 10px;color:#64748b">RGB</td><td>rgb({r}, {g}, {b})</td></tr>'
```

### 9. 质因数分解器

预期结果：输入一个整数，得到质因数分解、正因数个数和约数和。

```input {id=fact}
number: number = 360 {min: 2, max: 1000000, step: 1, label: 整数}
```

```python {in=fact, out=table, run=watch}
import json, os

n = int(os.environ["number"])
if n < 2:
    print(json.dumps({"columns": ["提示"], "rows": [["请输入 ≥ 2 的整数"]]}, ensure_ascii=False))
    raise SystemExit(0)

orig = n
factors = {}
d = 2
while d * d <= n:
    while n % d == 0:
        factors[d] = factors.get(d, 0) + 1
        n //= d
    d += 1 if d == 2 else 2
if n > 1:
    factors[n] = factors.get(n, 0) + 1

expr = " × ".join(f"{p}^{e}" for p, e in sorted(factors.items()))
div_count = 1
div_sum = 1
for p, e in sorted(factors.items()):
    div_count *= e + 1
    div_sum *= (p ** (e + 1) - 1) // (p - 1)

rows = [["分解式", f"{orig} = {expr}"]]
for p, e in sorted(factors.items()):
    rows.append([f"质因子 {p}", f"指数 {e}，即 {p}^{e}"])
rows.append(["正因数个数", str(div_count)])
rows.append(["约数和", str(div_sum)])
print(json.dumps({"columns": ["项目", "值"], "rows": rows}, ensure_ascii=False))
```

### 10. 目录占用 Top N

#### 10.1 bash 版（Mac & Linux）

预期结果：打开笔记就自动跑一次，列出当前目录下最占空间的子项，方便清理。改目录或条数立刻重算。默认统计本笔记所在目录。

```input {id=disk}
path: text   = "." {label: 目录}
top:  number = 10  {slider: 5..20, step: 1, label: 显示条数}
```

```bash {in=disk, out=table, run=open+watch}
du -sk "${path}"/* 2>/dev/null | sort -rn | head -n "${top}" | awk '
{
  size = $1 * 1024
  name = $0; sub(/^[0-9]+[ \t]+/, "", name)
  gsub(/\\/, "\\\\", name)
  gsub(/"/, "\\\"", name)
  rows = rows sprintf("%s[\"%s\",\"%.2f MB\"]", (rows ? "," : ""), name, size / 1048576)
}
END {
  printf "{\"columns\":[\"路径\",\"大小\"],\"rows\":[%s]}", rows
}'
```

> `du` 只统计非隐藏子项；目录为空时表格也为空，属正常。

#### 10.2 PowerShell 版（Windows）

预期结果：在 Windows 上打开笔记就自动跑一次（PowerShell 5.1 / 7 均可），列出指定目录下最占空间的子项。输入框直接填 `C:\Users\xxx`、相对路径或 `.` 都行，中文路径也能正常显示；目录不存在时给出一句提示，而不是空白表格。参数字段用 `dir` 而不是 `path`，避免和系统的 PATH 环境变量撞名。

```input {id=disk_win}
dir: text = "." {label: 目录（支持 C:\xxx、相对路径）}
top:  number = 10  {slider: 5..20, step: 1, label: 显示条数}
```

```powershell {in=disk_win, out=table, run=open+watch}
try { [Console]::OutputEncoding = [System.Text.Encoding]::UTF8 } catch {}  # 5.1 下中文不乱码

# 展开路径：相对路径基于笔记所在目录
$target = $env:dir
if (-not [System.IO.Path]::IsPathRooted($target)) {
    $target = Join-Path (Get-Location) $target
}
$target = [System.IO.Path]::GetFullPath($target)

if (-not (Test-Path -LiteralPath $target -PathType Container)) {
    $esc = $target -replace '\\', '\\\\' -replace '"', '\\"'
    Write-Output ('{"columns":["提示"],"rows":[["目录不存在或不可访问：{0}"]]}' -f $esc)
    exit 0
}

# 只统计一级子项（跳过以 . 开头的隐藏项）
$items = Get-ChildItem -LiteralPath $target -Force -ErrorAction SilentlyContinue |
    Where-Object { $_.Name -notlike '.*' }

$sizes = foreach ($item in $items) {
    if ($item.PSIsContainer) {
        $sum = (Get-ChildItem -LiteralPath $item.FullName -Recurse -Force -File -ErrorAction SilentlyContinue |
                Measure-Object -Property Length -Sum).Sum
        $size = if ($null -eq $sum) { 0 } else { [double]$sum }
    } else {
        $size = [double]$item.Length
    }
    [pscustomobject]@{ Name = $item.FullName; Size = $size }
}

$rows = @()
foreach ($r in ($sizes | Sort-Object Size -Descending | Select-Object -First ([int]$env:top))) {
    $esc = $r.Name -replace '\\', '\\\\' -replace '"', '\\"'
    $rows += , ('["{0}","{1:N2} MB"]' -f $esc, ($r.Size / 1MB))
}

Write-Output ('{{"columns":["路径","大小"],"rows":[{0}]}}' -f ($rows -join ','))
```

> 逐目录递归统计大小，比 `du` 慢，目录里文件多时首次运行可能花几秒；被拒绝访问的深层文件会静默跳过，数值可能略小。PowerShell 5.1 下已强制 UTF-8 输出，中文路径不会乱码。
