# 可交互组件例子

## 一、房贷计算器（滑块 + 自动重算）

预期结果：下面出现一组控件（滑块、数字框、下拉、勾选框）。拖动任意一项，控件和代码块之间的月供跟着变。

> 自动触发（`run=watch` / `run=open`）沿用设置里的「运行前二次确认」：开着的话**本次会话只问一次**，答应之后就不再打扰，重开应用才会再问；关掉则一次都不问。点运行按钮不受影响，仍然每次都问。

```input {id=loan}
principal: number = 500000 {slider: 100000..3000000, step: 50000, label: 贷款总额, unit: 元}
rate:      number = 3.85   {slider: 1..8, step: 0.05, label: 年利率, unit: %}
years:     select = [10, 20, 25, 30] {default: 30, label: 贷款年限, unit: 年}
equal:     bool   = true   {label: 等额本息}
```

```python {in=loan, out=markdown, run=open}
import os

principal = float(os.environ["principal"])
monthly_rate = float(os.environ["rate"]) / 100 / 12
months = int(os.environ["years"]) * 12

if os.environ["equal"] == "true":  # 等额本息
    growth = (1 + monthly_rate) ** months
    monthly = principal * monthly_rate * growth / (growth - 1)
    total = monthly * months
    print(f"**月供 {monthly:,.2f} 元**（每月固定）")
else:  # 等额本金
    first = principal / months + principal * monthly_rate
    last = principal / months * (1 + monthly_rate)
    total = (first + last) * months / 2
    print(f"**首月 {first:,.2f} 元，末月 {last:,.2f} 元**（逐月递减）")

print()
print(f"- 利息合计：{total - principal:,.2f} 元")
print(f"- 本息合计：{total:,.2f} 元")
```

## 二、单位换算（点运行，不自动重算）

预期结果：改数字后点右上角的运行按钮，结果出现在**运行输出面板**——这个块没写 `out=`，结果不会内联到笔记里。

```input {id=convert}
value: number = 100 {step: 10, label: 数值}
unit:  select = ["km→mile", "kg→lb", "°C→°F", "GB→GiB"] {label: 换算方式}
```

```python {in=convert}
import os

value = float(os.environ["value"])
table = {
    "km→mile": (value * 0.621371, "mile"),
    "kg→lb": (value * 2.204623, "lb"),
    "°C→°F": (value * 9 / 5 + 32, "°F"),
    "GB→GiB": (value * 1000 ** 3 / 1024 ** 3, "GiB"),
}
result, unit = table[os.environ["unit"]]
print(f"{value:g} → {result:.4f} {unit}")
```

## 三、表格当数据源（`in=table:`）

预期结果：下面的表格被当成数据读进脚本，输出渲染成一张**可点击表头排序**的汇总表。这个块写了 `result=below`，所以汇总表出现在代码**下方**。

### 销售数据

| 月份 | 渠道 | 金额 |
| :--- | :--- | ---: |
| 1月 | 线上 | 1200 |
| 1月 | 门店 | 860 |
| 2月 | 线上 | 1580 |
| 2月 | 门店 | 640 |
| 3月 | 线上 | 990 |
| 3月 | 门店 | 1310 |

```python {in=table:销售数据, out=table, result=below}
import json, os

rows = json.loads(os.environ["IDEA_NOTE_INPUT"])["rows"]

monthly = {}
for row in rows:
    monthly[row["月份"]] = monthly.get(row["月份"], 0) + float(row["金额"])

print("月份,合计,环比")
previous = None
for month, amount in monthly.items():
    delta = "—" if previous is None else f"{(amount - previous) / previous * 100:+.1f}%"
    print(f"{month},{amount:.0f},{delta}")
    previous = amount
```

## 五、输出成 HTML 组件（`out=html`）

预期结果：渲染成一排彩色进度条，分数越高颜色越绿。HTML 会先经过消毒（`<script>`、内联事件一律剥离），所以这里只能做静态展示。

```input {id=score}
math:    number = 82 {slider: 0..100, label: 数学, unit: 分}
english: number = 64 {slider: 0..100, label: 英语, unit: 分}
code:    number = 95 {slider: 0..100, label: 编程, unit: 分}
```

```python {in=score, out=html, run=watch}
import os

for label, key in [("数学", "math"), ("英语", "english"), ("编程", "code")]:
    score = int(os.environ[key])
    color = "#22c55e" if score >= 80 else "#f59e0b" if score >= 60 else "#ef4444"
    print(
        f'<div style="display:flex;align-items:center;gap:8px;margin:4px 0">'
        f'<span style="width:3em">{label}</span>'
        f'<span style="flex:1;background:#e5e7eb;border-radius:4px;height:10px">'
        f'<span style="display:block;width:{score}%;height:10px;'
        f'background:{color};border-radius:4px"></span>'
        f"</span><span>{score}</span></div>"
    )
```

## 六、读取外部文件（`file` 字段）

预期结果：先运行下面的「造数据」块生成 `sales-sample.csv`，再拖动「最少数量」，下方表格只留下达标的记录。

> 文件路径相对于本笔记，且**只允许工作区之内**——指向工作区外的路径会被拒绝并提示。

```python
from pathlib import Path

rows = [
    "product,region,qty,price",
    "键盘,华东,120,299",
    "键盘,华北,86,299",
    "显示器,华东,45,1499",
    "显示器,华南,61,1499",
    "耳机,华北,210,199",
]
Path("sales-sample.csv").write_text("\n".join(rows), encoding="utf-8")
print("已生成 sales-sample.csv")
```

```input {id=source}
data:    file   = "./sales-sample.csv" {as: csv, label: 数据文件}
minimum: number = 0 {slider: 0..250, step: 10, label: 最少数量, unit: 件}
```

```python {in=source, out=table, run=watch}
import json, os

payload = json.loads(os.environ["IDEA_NOTE_INPUT"])
rows = payload["data_data"]  # {as: csv} 已解析成对象数组
minimum = float(os.environ["minimum"])

print("产品,地区,数量,金额")
for row in rows:
    qty, price = int(row["qty"]), int(row["price"])
    if qty < minimum:
        continue
    print(f"{row['product']},{row['region']},{qty},{qty * price}")
```

也可以不经过 `input` 块，直接绑定文件——脚本用 `file_path` 拿到绝对路径：

```python {in=file:./sales-sample.csv, out=json}
import json, os

print(json.dumps({"文件": os.environ["file_path"], "行数": len(rows)}, ensure_ascii=False))
```

## 八、磁盘占用：打开笔记时自动刷新（`run=open`）

预期结果：关掉这篇笔记再打开（或重开应用），下面的块**不用点运行**就自己跑了一次，上方出现刷新时间和磁盘占用。

> `run=open` 是唯一一个「没有任何手势」就执行代码的触发：**每打开一次笔记跑一次**（切换视图模式这类内部重建不算），只读模式下不触发，且本次会话第一次自动运行前会问一次——不同意就什么都不跑。
>
> 注意 `run=` 是单选：写了 `run=open` 就不会再监听控件，拖动滑块不重算，要么点运行按钮，要么改成 `run=watch`。

```python {run=open, out=table}
import datetime, shutil

total, used, free = shutil.disk_usage(".")
gb = 1024 ** 3

print("项目,数值")
print(f"刷新时间,{datetime.datetime.now():%H:%M:%S}")
print(f"磁盘已用,{used / gb:.1f} GB")
print(f"磁盘可用,{free / gb:.1f} GB")
print(f"使用率,{used / total * 100:.1f}%")
```
