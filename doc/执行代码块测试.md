# 执行代码块测试

这篇笔记用于测试 Markdown 代码块执行功能。可运行代码块右上角会同时显示运行和面板图标，复制图标独立显示；面板图标可以打开或隐藏代码运行面板，点击运行图标时也会自动打开。面板只显示当前文件的运行记录。

## Python

预期结果：显示 `Python: OK`、计算结果 `55` 和当前工作目录。

```python
from pathlib import Path

total = sum(range(1, 11))

print("Python: OK")
print(f"1 到 10 的和：{total}")
print(f"当前工作目录：{Path.cwd()}")
```

## JavaScript / Node

预期结果：显示 `Node: OK`、计算结果 `55` 和当前工作目录。

```javascript
const total = Array.from({ length: 10 }, (_, index) => index + 1)
  .reduce((sum, value) => sum + value, 0);

console.log("Node: OK");
console.log(`1 到 10 的和：${total}`);
console.log(`当前工作目录：${process.cwd()}`);
```

## Ruby

预期结果：显示 `Ruby: OK`、计算结果 `55` 和当前工作目录。

```ruby
total = (1..10).sum

puts "Ruby: OK"
puts "1 到 10 的和：#{total}"
puts "当前工作目录：#{Dir.pwd}"
```

Ruby 没有 Python `-u` 那样的关闭缓冲开关，输出经管道时是块缓冲的：脚本跑得久时，结果可能要到进程结束才一次性出现。需要边跑边看的话，在开头加一行 `$stdout.sync = true`。下面这段用来验证这一点。

```ruby
$stdout.sync = true

3.times do |index|
  puts "计数：#{index + 1}"
  sleep 0.5
end
```

## Perl

预期结果：显示 `Perl: OK`、计算结果 `55` 和当前工作目录。Perl 运行器带 `PERLIO=:unix`，输出是实时的，不需要额外设置 `$|`。

```perl
use strict;
use warnings;
use Cwd qw(getcwd);
use List::Util qw(sum);

my $total = sum(1 .. 10);

print "Perl: OK\n";
print "1 到 10 的和：$total\n";
print "当前工作目录：" . getcwd() . "\n";
```

## Bash

预期结果：显示 `Bash: OK`、计算结果 `55` 和当前工作目录。

```bash
total=0
for number in {1..10}; do
  total=$((total + number))
done

printf 'Bash: OK\n'
printf '1 到 10 的和：%s\n' "$total"
printf '当前工作目录：%s\n' "$PWD"
```

## PowerShell

此项需要系统已经安装 Windows PowerShell 或 PowerShell 7。预期结果：显示 `PowerShell: OK`、计算结果 `55` 和当前工作目录。

```powershell
$total = 1..10 | Measure-Object -Sum | Select-Object -ExpandProperty Sum

Write-Output "PowerShell: OK"
Write-Output "1 到 10 的和：$total"
Write-Output "当前工作目录：$(Get-Location)"
```

## 标准输出与错误输出

运行后，普通输出应使用正常文字颜色显示，错误输出应使用错误颜色显示。程序最终应以退出码 `0` 结束。

```python
import sys

print("这是一条标准输出")
print("这是一条错误输出", file=sys.stderr)
```

## 停止运行

运行下面的代码后，点击运行记录右上角的 **停止**。预期状态为 **已停止**，且计数不会继续增加。

```python
import time

for number in range(1, 31):
    print(f"计数：{number}", flush=True)
    time.sleep(1)
```

## 非零退出码

运行下面的代码后，预期运行状态显示 **退出码 3**。这是主动退出测试，不代表代码执行功能异常。

```python
import sys

print("准备以退出码 3 结束")
sys.exit(3)
```

## 自定义运行器

在「设置 → 代码块执行 → 自定义运行器」里点 **添加运行器**，填入下面任意一组，保存后回到这里运行对应的代码块。

| 语言标识 | 别名 | 命令 | 参数 | 扩展名 |
| --- | --- | --- | --- | --- |
| `deno` | `ts` | `deno` | `run -A` | `.ts` |
| `go` | | `go` | `run` | `.go` |
| `java` | | `java` | | `.java` |
| `tcl` | | `tclsh` | | `.tcl` |
| `awk` | | `awk` | `-f` | `.awk` |

只有「一条命令跑一个源文件」的语言能这样加。需要先编译再运行、需要交互输入、或要常驻的程序，请用代码块右上角的「在终端运行」。

以 Tcl 为例，配置好后下面这个代码块应显示 `Tcl: OK`。

```tcl
puts "Tcl: OK"
puts "当前工作目录：[pwd]"
```

表单会当场拦掉几类填法，可以顺手验一下：

- 语言标识填 `py` → 提示 `py 已被运行器「python」占用`
- 语言标识填 `python` → 提示 `python 是内置运行器，请在上面直接修改`
- 语言标识填 `mermaid` 或别名填 `output` → 提示是保留标识
- 扩展名填 `tcl`（不带点）→ 保存后自动补成 `.tcl`
