# AI笔记助手接入DeepSeek步骤


1. 访问DeepSeek开发平台官网 [https://platform.deepseek.com/](https://platform.deepseek.com/)
2. 充值10块钱
  ![](<assets/image 2.png>)
3. 点API Keys->创建API Key，记录下来这个`API key`
4. Idea Note打开设置->AI笔记助手，Base URL填`https://api.deepseek.com`，然后填入第3步的`API Key`，点击模型ID右边的按钮`从上游获取`，点击保存。
   ![](<assets/image 3.png>)
   
5. 打开AI笔记助手，选择DeepSeek模型，然后就可以使用了
   ![](<assets/ai-img.png>)
