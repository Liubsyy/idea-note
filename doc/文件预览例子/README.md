# 文件预览例子

用 Idea Note 打开本目录作为工作区，再打开下面的文件。

| 文件 | 可以体验的功能 |
| --- | --- |
| [交互页面.html](./交互页面.html) | 源码 / 预览 / 分屏，点击计数、脚本、相对路径资源 |
| [延迟初始化.html](./延迟初始化.html) | 点击预览才运行，5 秒异步初始化，返回源码后停止并重置 |
| [项目配置.json](./项目配置.json) | 只读格式化视图、源码编辑、一键格式化源码、大整数 |
| [项目配置.yaml](./项目配置.yaml) | 格式化视图与源码，注释、多文档、锚点和循环别名 |

## 试一试

1. 打开 HTML，默认显示源码，不创建预览或运行脚本。切换「预览」后点击「完成一项」。切换到分屏，修改源码中的「今日小目标」，约 300ms 后预览更新。切回源码会停止预览；再次预览或源码更新后，页面状态会重置。
2. 修改 `assets/page.css` 中的 `--accent` 颜色并保存，回到 HTML 点击「刷新预览」。外部 CSS、JS 等依赖需要保存后手动刷新。
3. 打开 JSON 或 YAML，默认显示只读的「格式化视图」，不会修改源码或使文件变为未保存状态。切换「源码」可以查看原始文本并编辑，格式化视图约 300ms 后同步更新。
4. 在源码模式点击「格式化源码」，才会把排版结果应用到源码。可用 `Ctrl+Z` 撤销，保存沿用应用原有机制。YAML 注释尽量保留，引号、换行等写法可能调整。
5. 在 JSON 源码中临时删掉最后一个 `}`，查看错误提示及上一次有效视图。此时点击「格式化源码」不会改动内容；修正语法后，视图自动恢复。

只读格式化视图不会自动写入文件。示例不需要网络、Node 服务或构建工具。

## HTML 加载测试

- 在 Idea Note 中打开 `延迟初始化.html`，停留源码 5 秒，再点击预览：页面显示的脚本开始时间应是点击预览的时间。切回源码再进入分屏，计数和时间从头开始。
- 此文件的 5 秒等待是页面自身的异步初始化动画。应用的加载动画用于等待资源和页面加载，两者不是同一阶段。
- 要确定性地验证应用的慢资源动画，在项目根目录执行 `npm run dev:preview-tests`，打开 [慢加载测试页](http://localhost:1427/tests/htmlPreviewLoading.browser.html)。测试服务器将脚本响应延迟 9 秒，不依赖外网；可手动点击预览、返回源码、重试，观察会话、执行和心跳计数。
- 点击测试页「运行自动测试」，或打开 [自动测试入口](http://localhost:1427/tests/htmlPreviewLoading.browser.html?auto=1)。覆盖默认源码不执行、取消后的迟到会话释放、慢资源等待、模式切换、停止脚本、错误重试、长时间加载提示与缺失资源。
- 浏览器测试模拟原生资源会话，原生 WebView 的平台差异仍需实机回归。加载动画和取消能处理异步资源等待；页面脚本的同步死循环不能靠 iframe 加载动画解决。
